# Oxocarbon for Vim

Clone the repository:

```sh
git clone https://github.com/whispcat/oxocarbon.theme ~/projects/oxocarbon.theme
```

Then add this to your `~/.vimrc`, using `oxocarbon-light` for the light style:

```vim
set termguicolors
set rtp+=~/projects/oxocarbon.theme/extras/vim
colorscheme oxocarbon-dark
```
