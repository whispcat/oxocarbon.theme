# Oxocarbon for Zed

Copy `oxocarbon_dark.json` and `oxocarbon_light.json` into `~/.config/zed/themes/`.
Then pick "Oxocarbon Dark" or "Oxocarbon Light" with `theme selector: toggle`
(<kbd>cmd-k cmd-t</kbd> on macOS, <kbd>ctrl-k ctrl-t</kbd> on Linux).

To follow the system appearance, set both in `settings.json`:

```json
{
  "theme": {
    "mode": "system",
    "dark": "Oxocarbon Dark",
    "light": "Oxocarbon Light"
  }
}
```
