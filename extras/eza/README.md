# Oxocarbon for eza

Themes for [eza](https://github.com/eza-community/eza), an `ls` replacement.

## Usage

Copy `oxocarbon_dark.yml` or `oxocarbon_light.yml` to `~/.config/eza/theme.yml`.

On macOS, eza looks for the theme in `~/Library/Application Support/eza` instead.
Set `EZA_CONFIG_DIR` to use another directory. The
[eza-themes](https://github.com/eza-community/eza-themes) repository has more
details.
