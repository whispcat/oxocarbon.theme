# Oxocarbon for Tailwind CSS v4

The Oxocarbon colors as theme variables for [Tailwind CSS](https://tailwindcss.com)
version 4.

## Usage

1. Copy `oxocarbon_dark.css`, `oxocarbon_light.css`, or both into your project.

2. Import them in the CSS file that Tailwind processes:

   ```css
   /* styles.css or whatever your CSS file is named */
   @import "tailwindcss";

   @import "./oxocarbon_dark.css";
   @import "./oxocarbon_light.css";
   ```

3. Use the colors like any other Tailwind color:

   ```html
   <button class="border border-oxocarbon-dark-border bg-oxocarbon-dark-bg text-oxocarbon-dark-fg">
     Click me!
   </button>
   ```
